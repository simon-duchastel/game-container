# reference_materials/

The authoritative rules for this game are the **Container (10th Anniversary Edition) rulebook**. The
engine cites it by page number in comments (e.g. `// pg. 9: produce as many as you are able to`), and no
rule here should be implemented from memory — read the page first.

## The rulebook PDF is not in this repository

`Container_Rulebook_v8.pdf` is **copyrighted**, so it is gitignored (`reference_materials/*.pdf`) and kept
local only. This directory is tracked purely for this note.

To work on the rules, drop your own copy here:

```
reference_materials/Container_Rulebook_v8.pdf
```

If you have the Game Hub platform monorepo checked out, its copy lives at
`reference_materials/Container_Rulebook_v8.pdf` in that repo — copy it across. It is never committed to
either repository.
